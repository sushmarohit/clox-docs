CLOX FREIGHT PLATFORM  /  UI SPECIFICATION

Driver web + mobile — the gates that stand between a job and a moving truck.

Web is a thin invite-and-profile shell. Mobile is the real product: pre-trip safety and mass gates, geofenced arrival, POD capture, breakdown reporting — designed for a cab, not a desk, with high-contrast dark chrome for outdoor glare and gloved thumbs.
