State & Local Admin — the same ops console, a smaller window onto it.

State Master Admin oversees one state: compliance, disputes, and the Local BDE team beneath them. Local BDE Admin runs one territory: growth pipeline and first-line support, mostly view-and-escalate. Every screen carries a scope badge so nobody forgets what they can't see.
